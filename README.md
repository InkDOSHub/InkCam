# InkCam

Use the iPhone camera as a webcam on the PC (up to 4K 30 fps), part of [InkDOS Hub](https://inkdoshub.github.io/).

- Web app: https://inkdoshub.github.io/InkCam/ (root of this repository, GitHub Pages)
- Windows app and virtual camera: [windows/](windows/), built by `.github/workflows/webcam-windows.yml` into the `webcam-windows` release.

Shared Hub files (theme, language, bar) come from `/assets/` on the same site.
